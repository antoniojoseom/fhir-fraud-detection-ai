# Auditoría de Historias Clínicas Electrónicas mediante IA y FHIR

Este repositorio contiene el desarrollo de mi Trabajo de Fin de Grado (TFG) para la Universidad de Sevilla.

## Objetivo
Detección de comportamientos anómalos y fraude en prescripciones médicas utilizando el estándar HL7 FHIR y modelos de Machine Learning.

## Estructura del Proyecto
- `/data`: Archivos JSON de pacientes sintéticos (FHIR Bundles).
- `/scripts`: Scripts de procesamiento y análisis.
- `/notebooks`: Experimentos con modelos de IA.
